# Guilherme Holanda

Engenheiro de Sistemas, técnico em Telecomunicações pelo IFCE. Trabalho com firmware, automação industrial e visão computacional, quase sempre em Python e C/C++.

## Projetos

**LibrIA**: pipeline para criar um avatar intérprete de Libras. Processa mais de 15 mil vídeos com OpenCV e MediaPipe, extrai a pose do corpo e das mãos e leva o movimento para o Blender. Boa parte do trabalho é otimizar leitura de disco e paralelizar o processamento no Colab.

**Automação de esteira**: firmware em ESP32 para a linha de produção de uma fábrica. Controla motor por relé, lê sensores de passagem, conversa por MQTT e tem uma IHM com display e botões. O painel web que acompanha a linha em tempo real está em [dashboardira](https://github.com/guiholan/dashboardira).

**EduCare**: firmware e eletrônica de um dispositivo com Bluetooth Low Energy ligado a um app de alfabetização para crianças autistas.

**[Raízes Nordestinas](https://github.com/guiholan/raizes-nordestinas)**: site do grupo de tradições folclóricas, em Next.js e TypeScript.

Os repositórios `*-wokwi` são exercícios de eletrônica digital com Arduino e ESP32 (displays de 7 segmentos, multiplexação, registradores 74HC595, sensor ultrassônico), todos simuláveis no Wokwi.

## Ferramentas

Python, C, C++, TypeScript · ESP32, Arduino, MQTT · OpenCV, MediaPipe, Blender · Next.js · Git
